# seasonal-agriculture-performance-analysis
Seasonal Agriculture Performance Analysis — VOIS AICTE major project analyzing 4,000 farm records across Kharif, Rabi &amp; Zaid seasons in Python (Pandas, Seaborn, SciPy) on Google Colab. Covers data cleaning, EDA, ANOVA/correlation testing, and season-wise insights on yield, profit, irrigation efficiency, and crop performance.
